# 理论教程


理论教程共 13 章，以“执行—改技能—改权重”为主线，解释大模型智能体怎样调用机器人能力，以及怎样根据反馈改善系统。

十三章的正文都在本目录下，每章一个文件。下面按部分列出各章要回答的问题和各节的内容，章标题链接到正文。

- **导论**（[第 01 章](#chapter-01)）：认识机器人智能体系统。
- **执行**（[第 02 章](#chapter-02)—[第 06 章](#chapter-06)）：组织能力、状态与反馈，完成任务。
- **改技能**（[第 07 章](#chapter-07)—[第 08 章](#chapter-08)）：保存有效做法，根据失败修订。
- **改权重**（[第 09 章](#chapter-09)—[第 12 章](#chapter-12)）：评估并通过训练、数据与环境改善能力。
- **闭环**（[第 13 章](#chapter-13)）：连接不同改进过程，检查结果与证据。

## 导论

<a id="chapter-01"></a>
<a id="chapter-01-overview"></a>
<a id="chapter-01-agentic-comparison"></a>
### [第 01 章 导论](./chapter-01.md)

核心问题：机器人智能体是什么，大模型在其中承担什么，任务完成以后怎样让它下一次做得更好？

- **1.1 机器人智能体**：观察、决定、行动、检查的循环，“决定”这一步的三种做法，机器人智能体的定义。
- **1.2 Harness**：大模型、本体和 Harness 三个部分，Harness 承担的五个方面的工作。
- **1.3 从执行到改进**：修改技能与修改权重，智能体的两种角色，独立的评估，递归自我改进的含义。
- **本教程的内容安排**：理论各章的顺序，以及仿真实验和真机实战两部分。

## 第一部分 执行

<a id="chapter-02"></a>
### [第 02 章 能力接口与门控](./chapter-02.md)

核心问题：怎样把机器人的能力提供给大模型，同时让每次调用都有明确的执行范围？

- **2.1 原子能力与工具**：观测、动作和停止三类工具，工具定在现成的控制程序之上。
- **2.2 调用契约**：参数的单位和坐标系，调用的前提，返回的内容，以及写给大模型的使用建议。
- **2.3 入口门控**：每次调用在执行之前由代码检查，包括允许的工具、参数的范围、前提、动作之间的冲突和观测是否过时。
- **2.4 能力适配**：用适配层把同一组工具接到仿真环境和不同的机器人上。

<a id="chapter-03"></a>
### [第 03 章 编排](./chapter-03.md)

核心问题：任务被拆成多步以后，每一步由谁执行，执行后怎样决定下一步？

- **3.1 任务与步骤**：把任务分成阶段和步骤，每个阶段有可以观察到的完成条件。
- **3.2 编排方式**：由代码编排、由大模型编排和介于两者之间的做法，各自适合的情况。
- **3.3 调用与反馈**：进入下一个步骤的依据，每次决定以后执行多少动作，时间和预算。
- **3.4 控制权交接**：大模型、策略、机器人自带的程序和人之间的交接，任务怎样结束。

<a id="chapter-04"></a>
### [第 04 章 监控与恢复](./chapter-04.md)

核心问题：动作已经被受理，怎样知道它是否完成，失败以后又该做什么？

- **4.1 受理、执行与效果**：区分请求被受理、动作执行结束和预期的效果达到三个环节。
- **4.2 检查的时机与办法**：执行之前、执行过程中和执行之后各检查什么，由代码还是由大模型检查。
- **4.3 超时与未知结果**：给调用设定时限，结果未知时先查询或者观测，处理迟到的结果和被打断的动作。
- **4.4 恢复与放弃**：从失败留下的状态出发恢复，限制恢复的次数，做不成时及时停止。

<a id="chapter-05"></a>
### [第 05 章 记忆](./chapter-05.md)

核心问题：怎样把任务经验变成后续决策可用的信息，并避免继续使用过时的事实？

- **5.1 记忆内容**：历史、状态和经验三种内容，各自的用途。
- **5.2 来源与时效**：区分观测、推断和告知，记下时间和成立的条件，判断内容是否过时。
- **5.3 更新与检索**：以新的观测为准更新状态，选择每一轮放进输入的内容，其余的按需查询。
- **5.4 日志与记忆**：完整地保留执行记录，从中提取和整合经验。

<a id="chapter-06"></a>
### [第 06 章 分层系统](./chapter-06.md)

核心问题：慢速的任务决策怎样与快速的策略和控制过程协作？

- **6.1 层次与职责**：决策层、策略层和控制层，各层负责什么。
- **6.2 时间尺度**：决策延迟、控制频率，指令的有效期和执行上限。
- **6.3 策略作为工具**：决策层通过工具调用策略层，契约里写明输入、适用范围和结束条件。
- **6.4 层间异常**：上层停顿、状态过时和执行中断时各层的责任。

## 第二部分 改技能

<a id="chapter-07"></a>
### [第 07 章 技能与技能库](./chapter-07.md)

核心问题：怎样把一次有效的做法整理成别人和后续任务可以复用的技能？

- **7.1 技能的形式与边界**：文本技能与可执行技能，技能和工具、策略、经验的区别。
- **7.2 技能包结构**：说明文件、清单、代码和验证记录，名称和描述供大模型选择。
- **7.3 适用范围**：前置条件、执行期间的条件、后置条件，占用的资源，失败和停止时的行为。
- **7.4 入库与复用**：入库之前的四层检查，验证记录和版本，技能的查找与复用。

<a id="chapter-08"></a>
### [第 08 章 技能与 Harness 的演化](./chapter-08.md)

核心问题：根据失败做出的修改，怎样证明它值得保留？

- **8.1 从记录提出修订**：从执行记录找出失败的原因，把失败做成测试，把修订写成可以检查的假设。
- **8.2 候选版本**：改动范围尽量小的候选版本，不在修订范围之内的内容，每个候选版本的记录。
- **8.3 回归与留出评估**：在同样的条件下比较新旧版本，用到原来失败的任务、原来能完成的任务和留出的任务三组。
- **8.4 保留与回滚**：事先定好保留的规则，新版本分步启用，回滚与技能的停用。

## 第三部分 改权重

<a id="chapter-09"></a>
### [第 09 章 评估与验证](./chapter-09.md)

核心问题：谁来判定成功，怎样检查这把“尺子”本身是否可靠？

- **9.1 成功判据**：看哪些量、在什么时刻看、有哪些约束、依据谁的观测。
- **9.2 评分规则与权限**：执行者、评分器和参考真值三方分开。
- **9.3 假成功与评分漏洞**：成功率偏高的四种原因，用结果已知的情况检验评分器。
- **9.4 结果比较**：回合数与置信区间，配对比较，报告评估结果时要写明的内容。

<a id="chapter-10"></a>
### [第 10 章 智能体驱动的机器人策略训练](./chapter-10.md)

核心问题：智能体怎样参与训练工作流，而训练结果又怎样被独立检查？

- **10.1 训练基础**：什么时候值得训练，模仿学习与强化学习，损失、奖励和检查点，训练的信号与任务是否完成的区别。
- **10.2 智能体的参与方式**：设计奖励、修改代码和配置、安排实验、分析结果，仍然由人负责的部分。
- **10.3 固定预算循环**：可以修改的范围，每次运行的预算和记录，按固定的评估挑选检查点和候选。
- **10.4 策略接入**：把训练好的策略以工具的形式接回任务系统，权重的版本和验证记录。
- **10.5 大模型的微调**：微调与蒸馏，训练用的执行记录的要求，训练大模型时的失败方式。

<a id="chapter-11"></a>
### [第 11 章 智能体采集与整理机器人数据](./chapter-11.md)

核心问题：智能体能承担哪些数据工作，怎样知道整理后的数据适合后续使用？

- **11.1 数据从哪里来**：人的示范、仿真里生成的轨迹和已有的轨迹。
- **11.2 采集中的智能体**：安排任务、监视执行、判定成功和复位，由人事先定好的内容。
- **11.3 标注与质量检查**：标注，以及从时间、状态和动作、回合、整个数据集四个层次检查。
- **11.4 数据版本与用途**：数据集说明、处理记录、版本和划分，用训练出的模型检验数据。

<a id="chapter-12"></a>
### [第 12 章 智能体搭建仿真场景与任务](./chapter-12.md)

核心问题：一个生成的场景能够加载，是否就适合执行任务或训练？

- **12.1 场景与资产**：形状与碰撞形状、尺寸、质量、摩擦和关节。
- **12.2 任务配置**：场景、抽取起始布局的规则、成功判据和参考解法，版本和种子。
- **12.3 生成方式**：受约束地填写配置与自由编写代码的区别。
- **12.4 可用性检查**：重叠、静置、可解性和复位等各项检查，训练和评估对场景的不同要求。

## 收尾 闭环与证据

<a id="chapter-13"></a>
### [第 13 章 闭环：递归自我改进与证据](./chapter-13.md)

核心问题：执行、技能修改和策略训练怎样形成改进过程，什么证据足以支持结论？

- **13.1 选择改进对象**：先排除评估和场景的问题，再在 Harness、策略、数据和大模型之间选择。
- **13.2 连接改进流程**：执行、诊断、选择对象、提出候选版本、验证、保留或者回滚，每一轮留一份改进记录。
- **13.3 人与智能体的分工**：循环里的各步可以自动进行，循环的规则由人事先定好。
- **13.4 递归与边界**：区分一次改进、持续改进和递归改进，各自需要的证据。
